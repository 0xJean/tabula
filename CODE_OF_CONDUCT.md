# Tabula Code of Conduct

Everyone is welcome to ask questions, report problems, contribute code and review changes, regardless of background, identity or experience. These expectations apply to contributors and maintainers in all Tabula project spaces.

## Working together

- Critique the change. When you disagree, point to a requirement, an example or a test result and give the author room to respond.
- Treat questions and corrections with respect. If a conversation gets heated, pause and give others time to reply.
- Get permission before sharing someone's personal information or private correspondence.

Harassment, discriminatory remarks, threats, personal attacks and repeated unwanted contact are grounds for moderation.

## Reporting and moderation

For help with a project discussion, mention @0xJean on the issue or pull request and ask for moderation. You can ask for a private follow-up and keep personal details out of the public thread.

To report abuse on GitHub privately, including conduct by a maintainer, send GitHub Support a link to the content and a brief account of what happened. [GitHub abuse reporting form](https://support.github.com/contact/report-abuse)

Maintainers consider the context, severity and any pattern of behavior. They may ask someone to change their conduct, remove abusive content, lock a thread or restrict participation.
